# P3.8 · 自定义地形核心取证、离线生成器候选校验与多建筑材料自动识别

> 研发阶段：P3.8 实际源码与受控正反例已编写，须以双版本 Java25/Gradle9.6.1 clean build、真正 Fabric GUI 自动取证和独立FULL/Z3验收为准。**不能仅凭编译成功宣传已经破解未知自定义服务器的完整64位世界种子。**

## 研究目标（优先级）

WorldSeedLab 的研究重点是**普通 Fabric 客户端真实可见的自定义地形、群系、地下分层和生成器关系**，并在条件成立时反推世界 Seed。沙漠神殿、海底神殿、冷暖海底遗迹、沉船及其他建筑只是补充证据，不是项目的全部目标。结构材料、完整轮廓、真实生成起点和 Seed 四者必须独立分级。

## 一键联合取证

- 游戏内输入一次 `/wsl auto on`，或 F8 研究面板使用 **一键联合取证**，同时开启 P1 三维 quart 群系、P2 WORLD_SURFACE 高度、P2.2 真实地表/海床/MOTION_BLOCKING/地下 STRATA，以及 P2.6 多建筑材料线索与 P3.6 沙漠神殿完整21×21几何。
- **STRATA 仅在自动采集期间临时启用**，不会覆盖 `probe.properties` 内用户自行选定的地形详情档位；停止联合采集后恢复原有模式。DETAIL 原始数据只写入本地世界 HMAC/维度目录 `terrain-detail.jsonl`，记录 CLIENT_OBSERVED 方块/流体/群系/海床证据，不能证明玩家可见地层未经人工或服务端修改。
- 仍仅读取客户端已加载 FULL 区块，保持 P3.6 额外256 BlockState/Tick、P2.6额外64 BlockState/Tick、P2.2额外24 BlockState/Tick 的有界预算，各自独立；绝不发包请求新区块、读取服务端 StructureStart、世界Seed或自动后台启动 Z3。
- F8 液态玻璃面板主按钮改为自动联合取证；聊天 `/wsl help` 提供中文分组操作说明，`/wsl auto status` / `/wsl status` 输出逐行、加粗、彩色状态。采集开始、停止、维度更换、写盘状态均遵守旧世界隔离和后台安全边界。

## P3.8 多结构识别：强制分清材料候选与已验证轮廓

- P2.6 `structure-scanned-v2.csv` 和 `structure-candidates-v2.jsonl` 是单独版本的扫描与候选材料索引；旧 `v1` 数据保留，升级后新模型可重新扫描此前被旧阈值漏过的已加载区块。
- 当区块真实 WORLD_SURFACE 与 OCEAN_FLOOR 差值表明有较深水体时，在固定每Tick 64次方块读取预算内，按8×8列采样水面/海床邻域；其他地形保持4×4列稀疏扫描。这**可能改善**海底遗迹和沉船材料检出，不能保证每座建筑都命中，也不能把“扫过未发现”解释为此处无自然结构。
- 材料组合自动候选包含海洋神殿、暖水/冷水海底遗迹、沉船、水下废弃传送门以及远古城市、试炼密室、末地城、下界要塞和堡垒遗迹等可辨识材料线索；合成正反例必须校验普通砂岩、海床碎石、普通木板、孤立海晶石、矿物和仅有幽匿方块不能被升级为真正的结构起点。
- **目前完整21×21可见轮廓及独立FULL StructureStart真值验收仍只对应沙漠神殿。** 其余类型均只能保存 `WEAK/MATERIAL_PATTERN` 候选和真实材料数量；未经该结构专属的真实几何模板、不同朝向校准及独立自然来源证据，绝不能送入 RandomSpread low48 或完整64位求解器。

## 地形反演研究算法：带真实客户端证据的条件候选排除

`P38TerrainCandidateAudit` 为独立纯Java、仅离线调用的前向生成器模型接口，用于**限定的候选 Seed**与已经保存的 `TerrainChunkSample` 真实16列高度比较：

1. 输入必须是同一 HMAC/维度/版本的3～64条真实地形区块，禁止重复点或跨世界拼接。至少需要3处相距≥1024格的样本；不够则 `INSUFFICIENT_INDEPENDENT_SAMPLES`。
2. 模型接口 `ForwardTerrainModel.predictedWorldSurface(seed, chunkX, chunkZ)` 必须由研究者提供真实可复算的独立世界生成实现；WorldSeedLab **不会将只凭名称或资料猜测的自定义生成器强行当作原版模型**。每次最多64个显式不同候选，每个必须给出16个高度点；未提供的数据不允许填充。
3. 前两处独立取样为 FIT，余下为 HOLDOUT；只有拟合匹配且留出也匹配才可标 `CONDITIONAL_MATCH_UNVERIFIED`，任一冲突立即 `REJECTED_BY_FIT` 或 `REJECTED_BY_HOLDOUT`。
4. **不论候选数量是否剩一、输入是否自称“控制模型”**，此接口都只能输出带假设的兼容性报告；真实生成器、结构Salt、区块生成历史、自然来源与完整64位Seed状态仍未知。真正求解未知自定义NoiseRouter参数/世界Seed仍属于后续更严格的生成器建模与大量独立证据研究，不能承诺能破解任何服务器。

## 独立验收与剩余研究

- 双版 clean build 必须执行 P2.6 / P3.8 新增多结构材料正反例、地形候选 2FIT+1HOLDOUT 正反例、所有历史 P2.7/P2.8/P2.9/P3.x 回归。
- 必须真正运行 Minecraft 专用服务器和 Fabric GUI，**只执行一次 `/wsl auto on`**，并实际落盘 P1群系、P2地形、P2.2 STRATA与4份沙漠神殿完整栅格；后验隔离FULL/StructureStart及真Z3+Java RNG为受控世界，不得向客户端注入真值。
- 海底神殿/海底遗迹/沉船材料识别的纯Java模拟验证**不等于真实 Minecraft 海洋世界的识别率或结构起点验收**。后续需要独立真实 FULL 水下结构样本、采样速度、误报/漏报、玩家改造和自定义生成器控制对照；在通过之前保持“材料候选”标记。
- 用户真实服务器数据必须留本机，不上传地址、坐标、HMAC密钥、原始 ZIP 或私人项目代码。P3.7已实现的离线真实群系/地形审计继续保留、绝不转成在线自动完整64位暴力求解。
