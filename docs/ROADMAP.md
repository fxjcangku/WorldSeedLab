# WorldSeedLab / Research Roadmap

> 更新时间：2026-10-14 · 当前阶段：P0 Foundation
>
> 这是一份研究计划，不是功能完成列表。所有支持版本、算法和实验结论都以真实源码及可复现测试为准。

## 项目目标

构建独立的 Fabric 客户端研究工具，采集普通玩家在正常加载范围内能够观测到的原版及自定义世界生成证据，检验世界生成兼容性，并在算法和数据条件允许时研究结构种子、完整世界 Seed 的候选反推及独立验证。

- 主研究目标：Minecraft Java **26.2** 的自定义地形与原版结构混合服务器。
- 兼容目标：Minecraft Java **26.1.2 / 26.2**。
- 已知边界：服务器地图历史未知；可能混有旧区块、预生成区块或改造结构。
- 开发约束：**Java 25 / Fabric / Mojang Mojmap**；双版本差异独立处理。
- 原创原则：不复制既有破解工具源码，不直接移植私有 yiyiaddon 代码。

## P1 / World Probe — 数据观测

- [ ] 真实群系观察：已加载区块中的群系采样，与仅注册的群系分离。
- [ ] 维度、服务器实例与世界生成版本的分区存储。
- [ ] 手动结构标记：类型、坐标、证据来源、确认等级。
- [ ] 基础自动结构检测的可行性评估，明确客户端不直接获得的服务器生成元数据。
- [ ] 样本去重、错误坐标修正、地图重置检测、离线导出。
- [ ] 中文研究面板与低开销后台观察。

**验收条件：** 使用已知种子的单人世界录制、导出、重新导入证据，保证重复性；断线重连不污染不同服务器数据。

## P2 / Compatibility — 生成规则兼容性

- [ ] 在已知 Seed 的 26.1.2 与 26.2 世界，验证独立的原版结构放置模型。
- [ ] 测试结构起始区块与建筑可见坐标的差异。
- [ ] 自建数据包构造“地形变动但结构规则保留”的正例。
- [ ] 构造结构盐值/间距变更、人工建筑和跨版本混合区块的反例。
- [ ] 输出明确的 `compatible / incompatible / insufficient_evidence / unknown` 诊断结论。

**验收条件：** 能用独立留出样本证明兼容性判断，并识别刻意构造的错误输入，而不是只用单一个案得到“通过”。

## P3 / Solver Research — 种子候选

- [ ] 从已验证的结构生成模型研究约束与候选搜索。
- [ ] 明确结构种子、低位种子、64 位世界 Seed 等结果类别。
- [ ] 对候选集进行去重、边界检测、假阳性分析。
- [ ] 研究原版与自定义群系证据是否能够用于进一步筛选候选。
- [ ] 设置资源预算、超时中断、结果持久化和失败解释。

**研究风险：** 若服务器结构不遵守可识别的已知生成规则，可能无法使用原版模型得到任何可信候选。

## P4 / Verification — 结论复核

- [ ] 使用未参与求解的结构/群系证据进行独立验证。
- [ ] 输出可复核报告：证据来源、生成规则、候选、置信边界、验证样本与失败原因。
- [ ] 对不同版本、不同维度和混合历史区块给出独立结论。
- [ ] 建立匿名化测试数据、性能基准与可复现回归集。
- [ ] 满足实测条件后再讨论首次预览版 Release。

**验收条件：** 不将推测性结果标记为“真实完整 Seed”，报告能明确回答“为什么成立，哪里仍未知”。

## 不在本项目第一阶段范围内

- 替服务器读取 `level.dat`、后台配置或管理员权限数据；
- 对所有插件地形生成器作出保证；
- 未经验证的“实时自动破解全部服务器 Seed”宣传；
- 与 yiyiaddon 共享或公开其私有源码、服务器坐标和用户记录。

**下一项工作：** 讨论并落实 P0 的最小可加载 Fabric 工程与已知 Seed 测试环境。
