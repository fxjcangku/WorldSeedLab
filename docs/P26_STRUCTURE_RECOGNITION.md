# WorldSeedLab · P2.6 原创结构候选识别

> Minecraft 26.1.2 / 26.2 · Fabric · Java 25 · Mojmap。研究预览；尚未实现 Seed 求解器。

## 研究方向

服主可能使用假矿、自定义地形和人工建筑阻止玩家通过传统原版证据还原世界。P2.6 通过已加载区块的方块**材料组合**找出值得人工复核的候选建筑，绝不假装取得真实结构起始区块。

## 如何使用

1. 正常进入允许研究模组的世界，按 F8 并手动开启主采集。
2. 执行 `/wsl structures on` 或在大尺寸液态玻璃界面点击“结构侦测：关”切换开启。
3. 在海底神殿、沙漠神殿、沉船附近正常探索。未触发识别不代表建筑不存在。
4. 通过 `/wsl structures` 查看开启状态、近邻候选组数和已写入证据数量。
5. 通过 `/wsl structures off` 停止额外材料扫描；`/wsl report` 输出中文摘要；`/wsl path` 查找原始文件。

每次客户端启动、退出、断线或换维度，结构检测一律恢复为关闭；仅开启 P1 群系采集**不会**自动启动 P2.6。

## 已实现的首批材料线索

| 类型 | 线索 | 可信度上限 |
|---|---|---|
| 海底神殿 | 海晶石、暗海晶石、海晶灯 | MATERIAL_PATTERN（材料组合） |
| 沙漠神殿 | 沙石、切制/錾制砂岩、橙/蓝陶瓦 | MATERIAL_PATTERN（材料组合） |
| 沉船 | 水域附近木板、楼梯、活板门 | WEAK（低置信线索） |

**可信度仅衡量检测材料组合，不是自然生成概率，更不是 Seed 正确率。** 玩家建造、服务器复制的结构模板仍可能满足完全相同的特征。船坞、水上房屋也可能触发弱沉船候选。村庄、刷怪地牢、矿井等目前尚无可靠的自动模板识别。

## 防伪矿与性能

- 钻石矿、绿宝石矿、铁矿及其它含 ore 的方块不会进入材料结构指纹；客户端看到的矿石分布不能被认定为天然生成。
- 只读当前已加载 FULL 区块，无主动区块加载、额外网络请求或服务器权限。
- 16 个水平列；按地表和海床高度图的 ±12 方块窗口、每 2 方块取一次，重复方块去重。
- 每 tick 最多 64 次方块状态读取，仅持有一个区块扫描游标；只使用既有有界异步文件队列。
- 中途区块卸载时舍弃未完成的结果；磁盘背压时保留完成数据等待写入。
- 扫描完成不等于证明没有结构。模型版本更新后应重新建立单独扫描索引。

## 数据与隐私

原始数据保存在当前 HMAC 世界纪元/维度目录下：

- `structure-candidates-v1.jsonl`：命中的结构材料线索、置信等级、原始区块坐标、检测高度范围和材料证据数量。
- `structure-scanned-v1.csv`：已完成当前稀疏扫描的区块进度；没有候选并不构成缺席证明。
- `research-report.txt`：不含精确区块坐标的中文统计汇总。

候选文件始终写明 `natural_origin_verified=false`、`structure_start_known=false`、`uses_ore_seed_evidence=false`。**这些材料候选不会直接交给 Seed 求解器**，也不会出现在“已验证结构起点”数据集中。

优先发送研究汇总报告。原始区块位置可能泄露私人服务器地点，公开分享前请确认服务器规则并脱敏。绝不能发送 `identity.key`。
