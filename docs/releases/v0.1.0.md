**从可观测的世界证据出发，让每一个种子候选都有据可查。**

WorldSeedLab 初代版开放下载。这是一个独立的 Fabric 客户端世界生成研究工具，支持 Minecraft Java **26.1.2 / 26.2**。记录真实群系、地形与建筑线索，查看已探索地图，为生成规则与种子研究保存可复核的本地证据。

本次发布为 **v0.1.0 初代研究预览**。

### 初代版带来了什么

- **中文研究面板**：按 **F8** 或输入 `/wsl gui`，查看采集状态与设置。
- **一次授权联合取证**：输入 `/wsl auto on`，开始采集已加载区块的群系、基础地形与结构材料线索，并尝试保存完整可见的 **21×21 沙漠神殿轮廓**。`/wsl auto status` 查看进度，`/wsl auto off` 停止。
- **真实已探索地图**：输入 `/wsl map`，切换地表群系、指定 Y 高度群系与地形高度图；未采集区域保持未知。
- **中文研究报告**：输入 `/wsl report` 导出汇总，`/wsl path` 找到本机证据目录。
- **可选地下取证**：需要研究地下稀疏剖面时，先在面板或 `/wsl detail` 中选择 `STRATA`，再开启采集。默认档位为 `OFF`。

### 下载与安装

需要 **Java 25、Fabric Loader 0.19.5 或更新版本**，以及对应游戏版本的 Fabric API。

| Minecraft | 下载文件 | 本次构建使用的 Fabric API |
| --- | --- | --- |
| 26.1.2 | `WorldSeedLab-26.1.2-0.1.0.jar` | `0.155.3+26.1.2` |
| 26.2 | `WorldSeedLab-26.2-0.1.0.jar` | `0.161.0+26.2` |

将匹配游戏版本的 WorldSeedLab 与 Fabric API 放入客户端 `mods` 文件夹，启动后进入世界，按 F8 打开面板，或输入 `/wsl auto on` 开始联合取证。**两个 WorldSeedLab JAR 不要同时安装**；服务器无需安装。

普通使用者无需安装 Z3。它仅用于开发者显式执行的离线研究，客户端不会自动启动求解器。

### 当前研究进展与边界

既有双版本受控实验已通过真实 Fabric 图形客户端自动取证与独立复核：在公开已知 Seed 的实验世界中，客户端自主保存完整沙漠神殿轮廓，再由离线工具检查结构低 48 位候选。原版群系模型也已完成固定低 48 位条件下的全部 65,536 种高位检查。

**未知自定义服务器的生成器、Salt 与完整 64 位 Seed 仍待独立验证。** 当前完整轮廓自动取证仅针对沙漠神殿；被遮挡、改建、埋藏或高速跑图时可能漏采，材料匹配也无法认证建筑的自然生成来源。

### 数据与验证

采集默认关闭，只读取客户端已经加载的区块；断线、切服、切维度或写盘失败会停止。所有证据仅保存在本机，不主动上传，也不请求未加载区块。

分享问题时优先提供中文汇总报告。原始证据与地图包含坐标，请先脱敏；不要公开 `identity.key`。

本次发行的 **26.1.2 / 26.2 均已分别通过完整 `clean build`**，包括核心、证据隔离、地图、结构数学、实际 Z3、几何约束和自动取证的默认回归。构建使用 Java 25、Gradle 9.6.1 与项目 CI 同版 Z3 4.8.12；Z3 不随模组打包。

**本轮发行包未本机实机验收。** 上述受控图形客户端实验属于既有研发验收，不能替代本轮发行包或未知目标服务器的实测。随附 `SHA256SUMS.txt` 可用于校验两个 JAR。
